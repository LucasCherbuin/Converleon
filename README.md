## Work on project

To work on my project use the Dockerfile and the docker-compose.yml :

```bash
  1. builde the project with "docker build -t converleon" .
  2. use "docker run -it --rm converleon sh" to use the environnement
  3. for using the services run "docker compose -f docker-compsose.yml logs -f
```
